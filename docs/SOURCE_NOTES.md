# Source Notes & Portfolio Transparency

## Source materials used

This portfolio repository was structured from the following supplied academic materials:

- the Project Management summative report for the Cross-University Mobile App case study;
- the 2024/25 Project Management assessment brief;
- the Cross-University Mobile App Gantt Chart workbook.

## What was preserved

The repository preserves the source project's:

- fictitious-case-study framing;
- PID dates and budget values;
- project objectives and management approach;
- stakeholder impact/influence ratings;
- WBS phase structure;
- 30-task detailed schedule from the workbook;
- milestone and dependency information;
- risk-management discussion;
- sponsor and project-manager responsibilities;
- conclusion-level recommendation for a hybrid Agile + PRINCE2 approach.

## What was added for portfolio presentation

The following are **presentation and maintainability improvements**, not claims that they were part of the original submission:

- recruiter-friendly README and repository navigation;
- Markdown restructuring of the original project information;
- machine-readable CSV extracts for budget, stakeholders and schedule;
- Mermaid diagrams derived from source relationships;
- a lightweight automated validation script and GitHub Actions workflow.

## Source differences retained transparently

### PID vs Gantt end date

- PID end date: **31 August 2026**
- Detailed Gantt end date: **23 February 2026**

No tasks were invented to fill the period between those dates.

### Risk-register requirement vs supplied report

The assessment brief requested at least **10 fully documented risks** with pre/post action scores. The supplied report image shows **eight populated risk entries** and does not provide fully extractable pre/post scoring data in the available text. The repository documents that gap rather than silently completing the assessment after submission.

### Methodology requirement vs supplied report

The assessment brief requested explicit comparison of **Agile, Waterfall and PRINCE2**. The supplied report's conclusion supports a hybrid **Agile + PRINCE2** recommendation, but the provided source does not contain a clearly separated detailed three-method comparison. The repository therefore does not invent one.

## Privacy and presentation choice

The raw assessment documents are not duplicated in the public repository. The portfolio instead presents only the project information needed to demonstrate project-management skills in a clean, reviewable format.
